# 🛍️ Ecommerce Sales Dashboard | Power BI

## 📌 Project Overview

This project features an interactive Power BI dashboard designed to monitor ecommerce sales performance, profitability, product trends, and regional sales distribution.

The dashboard provides an overview of key performance indicators and enables comparisons across product categories and customer segments.

## 🎯 Project Objectives

- Monitor year-to-date sales and profit.
- Evaluate profit margins and sales quantity.
- Compare sales with the previous year.
- Identify the top-performing and bottom-performing products.
- Analyze category-wise and region-wise sales.
- Explore sales across Consumer, Corporate, and Home Office segments.
